1.6 IPv4 Addressing & Subnetting

Konfigurasi IPv4 Address

Router(config)# interface <interface>
Router(config-if)# ip address <ip-address> <subnet-mask>
Router(config-if)# ip address <ip-address> <subnet-mask> secondary
Router(config-if)# no ip address
Router(config-if)# no shutdown

Verifikasi Umum

Router# show ip interface brief
Router# show ip interface <interface>
Router# show interfaces <interface>
Router# show running-config interface <interface>
Router# show ip route connected
